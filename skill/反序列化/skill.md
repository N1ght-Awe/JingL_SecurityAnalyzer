---
name: 反序列化漏洞分析
description: CWE-502；审查 Java 原生及第三方反序列化的类型、配置、输入信任和可达行为。
---

## 1. 漏洞概述

反序列化入口不自动等于 RCE；区分对象构造、类型混淆、资源耗尽及真实危险副作用。

## 2. 危险点清单

ObjectInputStream/readObject、Fastjson autoType、Jackson 多态、XStream、Kryo、Redisson 编解码、Spring Session 及自定义反序列化器。

## 3. 分析步骤

定位实际依赖版本及解析实例；追踪不可信字节、类型选择、类路径、白名单/过滤器、资源限制和扩展回调。核验配置优先级及过滤失败处理。

## 4. 证据闭合验证

输入可控、具体解析配置允许相应能力、可达类型/逻辑导致目标影响；已知 CVE 需核验版本与前提，不要求所有未知缺陷必须先有 CVE。

## 5. 防护措施清单

实际类型白名单与能力/资源限制覆盖整条解析路径；过滤器存在、换成 JSON 或版本笼统“较新”都不能单独排除。

## 6. 常见误报模式

真实输入不可被相关威胁主体影响，或实际配置完整阻断所述危险行为；可信数据签名需在解析前绑定内容及可信来源。

## 7. 判定标准

按共享契约审定。仅解析成功、报错或存在依赖不算命令执行；未获得目标类路径/配置时明确缺口。

## 8. 置信度评估

用输入信任、版本、配置、可达类型及影响证据描述置信度。

## 9. 核心纪律

不新增易受攻击依赖或重写漏洞类来制造复现；测试真实目标，只宣称观测到的能力。
