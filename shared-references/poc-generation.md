# 按目标设计验证

对主流程筛选出的 P0/P1/P2 读取本文件，按漏洞影响决定验证所需层次，不再增加“高价值”筛选门槛。先写 `goal`、真实目标位置/版本、最小依赖、前置条件、漏洞触发断言和安全对照，再生成测试。测试以漏洞行为成立为 PASSED；修复后的安全回归另记，避免反转含义。

## 最小充分验证

| 类型 | 优先证明目标与边界 |
|---|---|
| SQL注入 | 实际 Mapper/查询构造进入兼容数据库后改变查询语义；仅捕获拼接文本只能支持构造缺陷，不算执行影响 |
| 命令注入 | 真实执行路径触发隔离的无害标记；分开证明 shell 解释、参数注入及可执行文件控制 |
| 路径穿越 | 真实文件操作越过临时基目录读取/写入测试标记；仅字符串逃逸不证明文件读取 |
| SSRF | 实际客户端访问本地受控禁止目标并验证重定向/解析行为；DNS 查询不等于 HTTP 访问或凭据获取 |
| 权限控制 | 两个测试主体、归属明确的资源和真实授权链；验证本应禁止的操作/读取，不以登录成功替代越权证明 |
| XSS | 真实渲染上下文在测试浏览器中产生无害标记；仅包含 HTML 文本不证明脚本执行 |
| 反序列化 | 实际库版本、配置和类型路径触发目标行为；仅 parse 成功或异常不能宣称 RCE |
| XXE | 实际解析实例解析受控实体或访问临时资源；不将解析异常视为成功 |
| 表达式注入、不安全反射 | 真实引擎/反射路径突破目标能力限制；能做普通运算不代表能执行命令 |
| CSV注入 | 目标表格软件/版本中公式被解释；仅文件前缀可作源码确认，重开/转存场景按目标选择 |
| 敏感信息写入日志 | 测试秘密经过实际日志/脱敏链后仍可恢复；不输出真实凭据 |
| 硬编码 | 证明值加载、打包或有效使用位置；不为确认仓库暴露而尝试生产凭据 |
| 网络安全配置 | 实际客户端/浏览器/安全链行为与敏感数据或操作相连；源码配置不能替代生效证据 |
| 弱随机数 | 证明安全用途和可预测来源；统计外观不能证明密码学安全，也不必为源码缺陷穷举真实令牌 |
| 资源消耗 | 受控小规模实验验证增长规律、限额失效或放大；禁止用实际服务崩溃作默认断言 |
| 输入校验 | 实际业务路径违反明确的安全不变量；普通校验异常不算漏洞 |
| 供应链与签名校验缺失 | 受控制品通过真实校验/加载路径，确认实际字节与可信身份绑定是否被绕过；仅上传成功不证明执行 |

## 工程约束

- 优先现有模块测试及项目锁定依赖。不得重写目标方法、替换待证授权/净化逻辑或新增易受攻击依赖来“复现”。
- mock 可替换外部计费、通知等无关服务，但不得用预设的 SQL、文件、网络或授权结果冒充实际行为；记录替换项和影响。
- 保留平台配置、代理、拦截器、事务及序列化相关上下文。证明仅涉及纯方法时无需启动整站；涉及安全链时局部方法测试不够。
- 同模块共享环境，每个用例独立状态；正负对照使用同一安全路径，仅改变待证条件。
- 生成物放目标仓之外的隔离工作目录或项目既有测试目录的临时分支，记录源版本和改动；不污染业务代码。无执行环境时保存计划和 BLOCKED 原因。
