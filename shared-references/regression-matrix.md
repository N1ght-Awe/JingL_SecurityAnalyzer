# 规则回归与真实环境验收

维护时读取，扫描时不加载。architecture 与 Python unittest 验证结构和数据契约，不验证漏洞本身。下列语义情形须结合规则人工检查；真实项目回归另留执行记录，不能因表格存在就声称已测试。

| 情形 | 预期 |
|---|---|
| 18 类索引及子 Skill | 全部可路由，九部分完整，无教学代码块，元数据可读 |
| P0 源码闭合但未执行 | 可为源码确认，仍 P0；不能称运行确认 |
| 手写漏洞副本或 mock 结果 | 不接受为真实目标执行 |
| PASS 缺目标/对照/断言/原始证据 | 报告校验拒绝 |
| 原始日志被修改或不存在 | 摘要校验拒绝 |
| 构建错误、零测试、超时、断言失败 | 分别保留状态与原因，不转误报 |
| 高危尚未完成审查 | 待审查在候选与统计中可追溯 |
| 防护实现缺失 / 部署未知 / 代码未读 | 分别缺失关键源码 / 待验证 / 待审查 |
| 路径字符串同前缀、符号链接 | 不仅凭 normalize/字符串 startsWith 排除 |
| DNS 校验后连接重新解析 | 不能宣称已防重绑定 |
| Java 参数数组或非 shell exec | 继续审程序语义，不直接确认/排除 |
| 过滤器/解析库/受限上下文名称 | 读取实际配置和能力 |
| 无对象注解但服务/数据库策略生效 | 以真实授权链判断；局部 DAO 测试不能代替接口授权 |
| 列表、空集合、默认值、批量对象 | 按业务政策检查范围，不把空结果当安全 |
| CORS 通配 origin + include | 不直接确认浏览器能读取敏感响应 |
| 敏感响应随后仅存内存 | 仍检查接收链路是否已泄露 |
| 上传/下载分别正常但共同抵达执行 | 闭合跨仓制品信任；缺签名单点不自动 RCE |
| 搜索截断、未覆盖语言、低级别未审 | 留统计与局限，不称全量无风险 |

真实环境为每个适用类型准备漏洞路径、防护生效路径、关键条件未知路径。核对目标行为和证据边界，再比较耗时、token、误报、漏检与未解决项。基准只放测试材料，不增加扫描常驻上下文。
