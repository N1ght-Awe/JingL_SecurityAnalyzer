# 传输与浏览器验证

只对已选定且已获相应测试授权的目标使用实际客户端、测试代理、抓包或浏览器。执行记录遵循 poc-execution.md，不固定工具品牌或为每条发现重复启动环境。

- TLS：核验实际证书和主机名验证、代理配置、请求/响应数据及攻击者所需网络位置。代理成功读取流量不能自动证明攻击者可获得代理信任证书。
- 明文：证明对应流确实携带敏感信息；记录网络边界。回环或内网不自动安全，也不自动可被任意外部攻击者监听。
- CORS：以真实浏览器 origin、凭据模式、预检、服务器返回头及可读取的敏感响应闭合。`Access-Control-Allow-Origin: *` 与 credentials=include 不允许共享响应，不能直接报作凭据窃取；反射 origin 等情形需单独验证。
- 认证/CSRF：核验实际会话传递和受保护操作；有 Bearer 字样不能自动判定所有端点免疫。
- 制品：TLS 保护通信，对可信发布者和实际执行字节的绑定仍需单独审查。缺少独立签名也不自动证明可篡改，应核验整个信任模型。

记录链路 ID、源码、端点、协议、敏感数据类别、TLS/代理状态、工具、环境、时间、原始证据、前提和影响。没有工具证据只标源码分析；不能用假设性 MITM 推翻所有业务防护。
