# 防护判据

强防护必须作用于确切字段、编码形态、分支、目标操作与主体，并读取实现及生效配置。弱防护仅减少某些风险；实现/条件未知为未知防护；完成相应范围检查仍无相关机制才记无防护。未知不得自动确认或排除；防护数量不能替代有效性。

| 类型 | 可支持排除的条件 | 不能自动判安全的信号 |
|---|---|---|
| SQL注入 | 值完整绑定；动态标识符映射为有限固定值 | 项目使用 ORM、一个字段参数化、未知工具函数 |
| 命令注入 | 程序固定且变量参数不改变危险语义；相应目标受到强约束 | 参数数组、引号、无 shell、固定配置名称 |
| 路径穿越 | 按路径组件检查真实边界并处理符号链接/竞争，写入检查真实父目录 | 字符串 startsWith、normalize 单独使用、允许点号的文件名正则 |
| SSRF | 限定业务允许目标，实际连接地址与校验一致，所有解析结果和重定向受控 | 一次 DNS 校验、仅 URL 正则、只禁止 localhost |
| XSS | 当前渲染上下文的有效编码或净化，覆盖后续转换 | 编码库名称、CSP、HttpOnly、其他上下文已转义 |
| XXE | 实际解析链关闭所需外部能力并处理不支持配置的失败 | 单个开关、未知解析器默认值、项目有 Jackson |
| 硬编码 | 证明非秘密、已撤销或只引用外部秘密且无有效回退值 | 高熵外观、测试目录、环境变量名称、Base64 |
| 敏感信息写入日志 | 当前实际日志路径输出前不可恢复地移除敏感值 | 日志级别、JSON 注解但日志调用 toString、另一路径脱敏 |
| 权限控制 | 可信主体与资源/操作政策绑定，覆盖所有相关分支 | 登录、操作注解、DAO 无 owner 字段或有框架注解 |
| 不安全反射 | 固定且安全的目标集合及成员能力边界 | 固定接口、包名前缀、setAccessible 名称 |
| 反序列化 | 具体版本、类型白名单、资源约束和扩展反序列化逻辑均适配目标 | 使用 JSON、ObjectInputFilter 存在、某库笼统“安全版本” |
| CSV注入 | 与目标消费工具兼容的文本处理或危险前缀拒绝，覆盖所有不可信单元格 | CSV 引号、统一加 Tab/单引号却未核验重开与转存 |
| 表达式注入 | 固定表达式绑定数据，或能力受限且不能抵达目标危险行为 | 沙箱名称、SimpleEvaluationContext 字样、关键字黑名单 |
| 弱随机数 | 实际安全随机源、足够熵及适用生命周期/尝试限制 | SecureRandom 名称但截断/固定种子、普通随机用于秘密 |
| 网络安全配置 | 当前边界的真实安全机制对所述风险生效 | 内网/回环绑定、HTTPS 字符串、代理信任系统证书 |
| 资源消耗 | 消耗前/中对相应资源有不可绕过的总量、并发、时限和取消约束 | 线程池、单次 readNBytes、仅上传压缩前大小限制 |
| 输入校验 | 生效的类型/范围/语义/状态规则覆盖安全不变量 | 只非空、正则格式、存在 Validation 注解 |
| 供应链与签名校验缺失 | 执行前实际字节绑定到可信来源，失败拒绝且不可被替换绕过 | 证书固定、同源未认证哈希、文件后缀、仅存在验签函数 |

已读实现的结论与适用条件按 control-knowledge.md 记录；新路径核查调用与校验结果、失败分支和后续变换，匹配时可直接复用该实现分析，不必逐次重读。

不存在与类型无关的“一项强防护保全链”。TLS 防护不等于制品签名；短期令牌不等于无敏感信息；凭据在内存使用不消除网络暴露。HTTPS 可信分发是否足以支持制品来源需按威胁模型和发布权限判断，不能一律认定缺签名即漏洞。
