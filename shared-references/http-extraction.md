# HTTP 入口提取

仅当验证目标依赖 HTTP 时加载。由实际路由与绑定规则生成请求，不猜测 host、端口、身份或样例业务数据。

记录：方法；类/方法组合路径；context-path 与网关重写；路径/查询/头/Cookie/body/multipart 参数；Content-Type；类型与序列化名称；必填/默认值；认证方式；CSRF；租户与对象归属；对应源码位置。

沿 DTO、继承、验证分组、自定义反序列化和实际服务调用补齐字段；缺失值保存待填项，不能声称请求可运行。非 HTTP 的 MQ/RPC/文件入口使用原有入口，不伪造 Controller。

Base URL 和测试身份来自用户授权环境。请求中的 token/对象 ID 用测试数据引用，不将生产秘密写入报告。校验 401/403/404、绑定失败和正常业务拒绝，均不能算到达危险 Sink。

有权限问题时必须经过真实过滤器/拦截器/安全链。请求成功只证明已获响应；是否越权以主体、资源、预期策略和实际结果共同确定。
